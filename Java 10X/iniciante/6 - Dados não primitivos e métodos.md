## 1 - Dados primitivos

> Tipos de dados que de maneira geral não recebem métodos de maneira padrão

## 2 - Dados não primitivos

> São tipos de dados que de maneira geral pode-se colocar métodos para fazer alterações na variável sem que seja mudado seu escopo

## Exemplo de dados não primitivos

``Dados não primitivos: String, Array, Class, enum``

## Métodos

- ``string.toUpperCase();`` Deixa em CAPS LOCK
- ``string.toLowerCase();`` Deixa em caixa baixa
