> Servem para gerar casos especificos

sintaxe:
```java
switch (variavel_codicao) {
	case 1:
		System.out.println("Caso a variável for igual a 1, esse bloco de código é executado");
		break;
	case 2:
		System.out.println("Caso a variável for igual a 2, esse bloco de código é executado");
		break;
	default:
		System.out.println("Caso a variável não fizer parte de nenhum dos outros casos, esse bloco de código é executado.");
		break;
}
```

lembre-se de sempre dar break em cada um dos cases
