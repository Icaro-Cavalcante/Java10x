## POO tem 3 pilares:

Herança
> Usar características de uma classe pai em outras classes filhos para assim poupar código e agilizar trabalho.

Polimorfismo
> Criar uma função única que pode ser utilizada em diferentes classes com diferentes características

Encapsulamento
> Capacidade de proteger variáveis e classes para que não haja vazamento e mantendo assim nossos objetos protegidos e encapsulados.
