> Serve para deixar métodos constantes, sem ser sobrescritos

## Sintaxe:

```java
final void metodo() {
	System.out.println("Texto");
}
```

# Atributos final

> Deixa os atributos constantes

## Sintaxe:

```java
final double altura = 1.75;
```

## Em interfaces:

Em interfaces é possível criar atributos final para criar constantes (não precisa necessariamente colocar final nesse caso)
