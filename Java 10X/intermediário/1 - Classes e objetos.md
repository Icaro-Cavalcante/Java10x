> Tudo é um objeto no java

Criando uma nova classe:
```java
public class Ninja {  
    String nome;  
    int idade;  
    String aldeia;  
    String patente;  
}
```
Devemos criar isso em outra java class que não é a main.

Então criamos um objeto a partir da classe:
```java
Ninja naruto = new Ninja();  
naruto.nome = "Naruto Uzumaki";  
naruto.idade = 15;  
naruto.aldeia = "Konoha";  
naruto.patente = "Jonin";
```
