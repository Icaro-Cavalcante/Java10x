HashSet não garante ordenação

TreeSet ordena os elementos

se for uma string, ele deixa em ordem alfabética

se for um int ele deixa em ordem crescente

ele faz essas ordenações usando uma `árvore do flamengo` (rubro negra)

## Importe

```java
import java.util.Set;  
import java.util.TreeSet;
```

## Inicialização

```java
Set<tipo> nome_set = new TreeSet<>();
```
