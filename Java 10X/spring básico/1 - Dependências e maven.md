Site para inicializar projetos Spring

https://start.spring.io/index.html

Na seção de project vamos escolher o Maven que é o padrão do mercado para gerenciar as dependências do projeto

A linguagem é o Java mesmo

Em group geralmete colocamos a empresa controladora do projeto. Temos uma convenção que colocamos o ponto primeiro e não depois

Ex: para `google.com` usamos `com.google`

Artifact é o nome da pasta do projeto e name é o nome do projeto em si

Packaging geralmente usamos o Jar

Então vamos adicionar as dependências, que são as bibliotecas externas que vamos usar no projeto

Nesse caso vamos usar o spring web

Então clicamos em generate para baixar o jar e extraímos ele. A partir daí é só abrir o projeto no IntelliJ
